# Paradise Nursery Shopping Application

Paradise Nursery là ứng dụng web bán cây cảnh trực tuyến được xây dựng bằng React và Redux Toolkit.

## Tính năng chính
- Landing Page giới thiệu cửa hàng với nút chuyển hướng nhanh.
- Danh mục sản phẩm được phân loại rõ ràng (Air Purifying, Aromatic, Medicinal).
- Thêm sản phẩm vào giỏ hàng, cập nhật số lượng và tính tổng tiền thời gian thực.
- Quản lý trạng thái giỏ hàng tập trung bằng Redux Toolkit.

## Công nghệ sử dụng
- React.js (Vite / Create React App)
- Redux Toolkit & React-Redux
- CSS3 Custom Styling
